# T-Winkle

## Tech Stack
- Java 21
- Spring Boot
- Maven
- Spring MVC
- Thymeleaf
- Bootstrap
- Spring Data JPA
- SQL Server
- Spring Security
- JWT
- WebSocket/STOMP
- Cloudinary
- Leaflet
- VNPay
- MoMo

## Development
Localhost-first.

## Run
1. Configure SQL Server connection in `application.properties`.
2. Run `TWinkleApplication.java` from IDE or use `./mvnw spring-boot:run`.
3. Access `http://localhost:8080`.
